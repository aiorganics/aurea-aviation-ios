AUREA AVIATION iOS APP

Website: https://ams.aureaaviation.in/
App name: Aurea Aviation
Bundle ID: com.aureaaviation.ams

This is a WKWebView iOS app that opens the Aurea Aviation website and uses the supplied logo.

NO-MAC BUILD
1. Create a GitHub repository on a Windows PC.
2. Upload the contents of this project to the repository.
3. Open Actions -> Build Aurea Aviation iOS app -> Run workflow.
4. Download the generated AureaAviation-unsigned.ipa artifact.
5. Use a sideloading/signing tool such as AltStore/AltServer with your own Apple ID to sign/install it on your iPhone.

The unsigned IPA cannot be installed directly on an iPhone. Do not put your Apple ID password in GitHub or in this project.

For normal App Store/TestFlight distribution, use an Apple Developer account and the Apple signing/distribution process.
